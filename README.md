# 🎮 Game

A fun, lightweight browser game that you can play instantly on **mobile or desktop** — no installation required.

Built with web technologies and designed for a simple, accessible gaming experience, this project can be played directly in your browser and is easy to explore, modify, and extend.

## ✨ Features

* 🎮 Play directly in your browser
* 📱 Mobile-friendly
* 💻 Desktop support
* ⚡ Lightweight and easy to run
* 🌐 No installation required
* 🛠️ Open source under the MIT License

## 🚀 Play Online

**Play the game:**
https://mscbuild.github.io/game/

## 📦 Getting Started

Clone the repository and open the project in your browser:

```bash
git clone https://github.com/mscbuild/game.git
cd game
```

Then open `index.html` in your browser.
